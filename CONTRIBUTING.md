# Contributing to STALMAS

[Español](CONTRIBUTING.es.md)

STALMAS is closed source, so there are no code pull requests in this repository. Even so, community feedback shapes the app. Here is how you can help:

## 1. Report bugs

> ⚠️ **Never paste passwords, API tokens, SSH keys, real IP addresses or private domains** in public issues or screenshots.

Before opening a report:
1. Check [Issues](https://github.com/PeterMagno/stalmas/issues) to see if the bug has already been reported.
2. Open a [Bug report](https://github.com/PeterMagno/stalmas/issues/new?template=bug_report.yml) and include:
   - **App version** (**Settings → About & legal**);
   - **Phone model and Android version**;
   - **Area** (Portainer, SSH terminal, AI assistant, Monitoring/widgets, Backup/settings);
   - **Steps to reproduce** and **what you expected**;
   - **Screenshots**, with any private data hidden first.

**From inside the app:** you can also open **Settings → About & legal → Report a problem**. STALMAS prepares an email draft to `report@stalmas.app` with recent technical errors (and local AI model metadata if applicable), hiding IPs, domains, tokens and passwords so you can review it before sending.

## 2. Propose ideas

- Share feature ideas in [Discussions → Ideas](https://github.com/PeterMagno/stalmas/discussions/categories/ideas) or open an [Idea issue](https://github.com/PeterMagno/stalmas/issues/new?template=idea.yml).
- Describe the problem you want to solve, how you would like it to work, and how you handle it today.
- **Vote with 👍** on existing ideas in **Discussions → Ideas**: post-launch ideas are prioritized based on community votes.

## 3. Help other users

- Answer questions and share tips in [Discussions → Q&A](https://github.com/PeterMagno/stalmas/discussions/categories/q-a).

## 4. Translations

- We are **not** accepting community translations for now. The app is currently maintained in English and Spanish.

## 5. Security & Conduct

- Do **not** report security vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).
- Participation in this repository is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
